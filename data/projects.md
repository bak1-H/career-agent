# Proyectos destacados

## Sistema de Control de Activos

- Organización: Falabella.
- Descripción: Aplicación para el control y auditoría de dispositivos usados en bodegas, con seguimiento del estado de cada activo.
- Backend: API REST en NestJS con TypeORM y PostgreSQL.
- Integración: capa BFF.
- Frontend: React, TypeScript y Tailwind CSS.
- Documentación: Swagger y OpenAPI.
- Testing: Jest.

## TennisApp

- Contexto: proyecto grupal de título de Analista Programador Computacional en DUOC UC.
- Descripción: Plataforma web para entrenadores y jugadores de tenis (partidos en vivo, estadísticas, notificaciones en tiempo real).
- Backend: Django y Python.
- Frontend: React y TypeScript.
- Despliegue: AWS EC2 y Docker Compose.
- CI/CD: GitHub Actions.

## Zenly

- Contexto: proyecto personal.
- Descripción: Aplicación web responsiva para que profesionales independientes gestionen turnos y clientes, con acceso por enlace al correo.
- Tecnología: React, TypeScript, Vite, Tailwind CSS y Supabase.
- Despliegue: Vercel (https://zenlycl.vercel.app).

## Danny Tortas

- Contexto: sitio web para un negocio real de pastelería y coctelería a pedido.
- Descripción: Landing page con galería y carta de precios; el pedido se cierra por WhatsApp.
- Tecnología: Astro y Tailwind CSS.
- Despliegue: Netlify (https://dannytortas.cl).

## Migración de cronjobs de Falabella

- Contexto: práctica profesional en Falabella (equipo de Automatización e Infraestructura).
- Descripción: Migración de procesos de automatización desde scripts Python a cronjobs en TypeScript sobre Kubernetes.
- Tecnología: TypeScript, Node.js, BigQuery, Docker, Helm y GitLab CI.
