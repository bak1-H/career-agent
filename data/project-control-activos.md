# Control de Activos

Control de Activos es un sistema de gestión y auditoría de equipos de bodega, desarrollado en Falabella. Incluye inventario de equipos, asignación y devolución, transferencias entre bodegas con recepción y resolución de discrepancias, regularización, conteos cíclicos con escaneo y validación de hallazgos, paneles de seguimiento, auditoría y administración de catálogos. Su arquitectura separa una aplicación React de una capa BFF y una API, ambas en NestJS: el BFF propaga solicitudes autenticadas a la API y agrega contexto de país. Usa React 18, Vite 6, TypeScript, Tailwind CSS 4, TanStack Query 5, Zustand 5, AG Grid y ApexCharts en el frontend, y NestJS 11, TypeORM 0.3 y PostgreSQL en el backend. Las operaciones críticas, como transferencias y escaneos, se ejecutan de forma transaccional. Incluye sincronización de datos con BigQuery, notificaciones programadas a Microsoft Teams mediante webhooks y procesamiento de Excel en Web Workers del navegador. Existen pruebas Jest para recuperación de workers en el frontend y autorización en el backend, además de Dockerfiles y configuración de GitLab CI.
